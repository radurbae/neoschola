## 4. Checklist Produksi Konten (Target Selesai 1 Hari)

### Persiapan Akun & Lingkungan Demo
- [ ] Jalankan perintah pembersihan data demo: `ALLOW_DEMO_RESET=true npm --workspace=apps/api run reset:demo` agar riwayat kembali ke kondisi awal yang bersih.
- [ ] Pastikan 3 akun uji coba siap digunakan di peramban:
  - `guru.ani@neoschola.demo` (Wali Kelas 4A)
  - `wali.budi@neoschola.demo` (Wali Murid Raka Pratama)
  - `admin.tu@neoschola.demo` (Admin Tata Usaha)
- [ ] Siapkan dua jendela browser terpisah (atau mode penyamaran/incognito) agar perpindahan antar akun saat perekaman berjalan mulus.

### Standar Teknis Perekaman Layar
- [ ] **Format Vertikal (9:16)**: Khusus konten Reels, TikTok, dan Shorts. Gunakan resolusi 1080 x 1920 piksel. Buka browser dalam mode inspeksi tampilan ponsel (device toolbar ukuran mobile 390 x 844 piksel).
- [ ] **Format Horizontal (16:9)**: Khusus demo proposal atau presentasi ke Kepala Sekolah / Yayasan. Gunakan resolusi minimal 1920 x 1080 piksel (layar desktop/laptop bersih).
- [ ] Nonaktifkan ekstensi browser yang tidak perlu dan bersihkan bookmark bar agar rekaman fokus pada antarmuka aplikasi.
- [ ] Gunakan zoom browser 100% atau 110% agar teks label tombol dan status tabel terbaca jelas di layar HP kecil.

### Pascaproduksi & Distribusi
- [ ] Tambahkan teks penjelas (captions) di bagian tengah-bawah video karena mayoritas penonton medsos memutar video tanpa suara.
- [ ] Pastikan tidak ada data nomor HP atau nama siswa sungguhan yang bocor saat rekam layar (hanya gunakan data bawaan demo).
- [ ] Cantumkan tautan neoschola.floc.site pada profil bio akun media sosial dan siapkan pesan otomatis WhatsApp pada +62-857-9170-2218.
